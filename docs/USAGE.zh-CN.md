# Seqvio Studio 使用指南

[返回首页](../README.md) · [English](USAGE.en.md)

本指南对应 **0.1.0 Windows x64 未签名测试版**。下文使用中文界面入口名称；当前没有已发布、已验收的 macOS 安装版。

## 安装与首次启动

从 [v0.1.0 Release](https://github.com/makesynt/seqvio-studio/releases/tag/v0.1.0) 的 Assets 下载安装 EXE 和 SHA256SUMS.txt。在下载目录打开 PowerShell：

```powershell
Get-FileHash -Algorithm SHA256 .\Seqvio-Studio-0.1.0-win-x64-Setup.exe
```

将结果与同一 Release 的校验文件核对。安装包约 188.8 MB，解压后的应用文件约 562.4 MB；此外还需要给项目、音频、视频和下载缓存预留空间。不能仅按安装包大小估算磁盘需求。

运行安装程序，选择安装目录，完成后通过桌面或开始菜单启动。安装版自带应用运行时和媒体工具，无需为 Seqvio 本身另外安装 Node.js、npm、Python 或 FFmpeg；你选择的 Agent CLI 仍需按其安装方式准备环境。

此版未签名，可能出现“未知发布者”“Windows 已保护你的电脑”等提示。核对来源后，是否能继续取决于设备提供的选项和安全策略；部分智能应用控制或企业策略会直接阻止运行。请记录具体拦截信息，不要将未启动误判为渲染故障。参考 [Microsoft 对 SmartScreen 的说明](https://learn.microsoft.com/windows/apps/package-and-deploy/smartscreen-reputation)。

## 配置创作引擎

先选择一个引擎，无需同时安装三种：

| 引擎 | 使用前准备 | 官方安装与配置说明 |
| --- | --- | --- |
| OpenCode | 本机 `opencode` CLI、可用 provider/model 和凭据 | [OpenCode 文档](https://opencode.ai/docs/) |
| Codex | 本机 `codex` CLI、登录及可用模型权限 | [Codex CLI 文档](https://developers.openai.com/codex/cli/) |
| Antigravity | 官方 `agy` CLI、登录及可用模型 | [Antigravity CLI 文档](https://antigravity.google/docs/getting-started?tab=cli) |

Windows 桌面应用需要能找到本机 CLI 可执行程序。先在终端验证所选 CLI 能启动、完成登录并实际访问模型，再重启 Seqvio。只有浏览器账号或其他应用的聊天登录，并不一定已经配置好对应 CLI。

打开 **设置 → 引擎与连接**，选择引擎，刷新并选择本机可用模型。模型留空时使用本机默认配置；执行“检测连接”。连接检测不代表模型一定有访问权限、余额或可用额度。如果能检测但任务失败，请按实际提供方错误处理。

如果 CLI 安装在非标准目录，可在启动 Seqvio 的进程环境中设置 `OPENCODE_CMD`、`CODEX_CMD` 或 `ANTIGRAVITY_CMD`，值为相应原生可执行文件的路径。不要把密钥填入创作说明或项目资料。

## 选择风格与配音

### 风格库

可从[风格包下载目录](STYLE-PACKS.md)获取 41 套可导入 ZIP 或合集。安装版已内置这些风格；需要个人副本时，下载单包并通过“自定义 → 导入风格包”导入。合集必须先解压，再逐个导入其中的 ZIP。

进入“风格库”，浏览 41 套内置风格。封面和静音短循环随包提供；打开完整样片时才下载相应视频，校验后缓存。短循环没有声音是预期行为，不表示配音损坏。

第一次预览完整样片需要能够访问 GitHub Releases。中断后可重试，下载器支持断点续传；完成下载后可离线播放。在样片预览中清理单个文件，或到 **设置 → 存储** 清理全部样片缓存。清理后下次观看需重新下载。

选择“使用此风格”开始创作。导入个人风格时使用受支持的 Skill 目录或 ZIP 包；完成视频后可提炼并审阅规则，保存为可复用风格，再导出分享。单次项目修改不会自动改变风格库。

### 配音方式

在项目的 **风格与配音** 中选择：

| 方式 | 适用情况 | 需要准备 |
| --- | --- | --- |
| Windows 系统语音 | 先验证制作流程，或本地离线配音 | 本机已安装的系统音色 |
| 无配音 | 静音画面、仅配乐或自行后期处理 | 无在线语音服务 |
| MiniMax API | 使用账号可用的在线系统或自定义音色 | 匹配国内站/国际站的 API Key、音色和额度 |
| 自托管 CosyVoice | 使用自己的语音服务和参考音色 | 可访问的服务地址、服务所需参考音频与配置 |
| Edge TTS、OpenAI、ElevenLabs | 使用对应入口支持的其他语音服务 | 各服务所需依赖、凭据及网络；需自行验证可用性 |

MiniMax 在界面选择国内/国际区域，填入对应 API Key，并保存设置。使用账号实际可用的模型和 `voice_id`；应用不自动跨区切换。调用在线服务可能计费，失败或取消后也应检查服务端的调用记录。

配音以实际音频时长驱动画面。字幕与句内短语时间目前为估算，不是自动语音识别后的逐词强制对齐。

## 完成第一个视频

### 1. 输入说明与资料

在首页输入主题或粘贴稿件，添加需要的文件或链接，选择风格、目标时长及引擎。建议第一次用短项目，例如：

> 制作一段约 45 秒的中文科普视频，面向第一次接触 AI 的办公人员，解释“AI 知识库如何帮助查找公司资料”。采用技术图解风格，包含提出问题、检索资料、生成带出处的回答三个步骤。每镜旁白简短，避免夸大能力，结尾提醒核对来源。

这是创作说明示例，生成内容及最终时长取决于模型、修改和实际配音。只添加准备交给所选模型处理的资料。

### 2. 审阅制作草案

开始创作后，Agent 根据资料提出核心观点、结构和秒数预算。在“制作草案”中检查是否符合受众和重点，通过会话提出修改，满意后确认。读取资料失败或内容不完整时，先补充或修正资料。

### 3. 审阅分镜与旁白

确认草案后，检查逐镜旁白、画面意图和视觉步骤。在继续之前修正文案与事实，并确认内容。完整旁白来自各镜已确认的旁白，不能只看最初输入的稿件。

### 4. 查看关键帧并确认规格

生成静态关键帧，查看文字、构图、素材、白板和视觉步骤。选择 **16:9 横屏 / 9:16 竖屏**、**720p / 1080p**；规格改变时，等待预览更新后再次检查。

检查质检提醒并完成当前版本的整体确认。“某一镜已审阅”不一定等于全片已确认；如果提示缺少确认，请进入对应审阅入口处理。修改旁白、画面、风格或输出规格后，受影响的确认可能失效，需要重新检查。

### 5. 制作、预览与导出

确认后继续制作配音与场景视频。等待合成，播放结果，检查声音、画面节奏、字幕和结尾，再导出成片。

当前默认输出为 **H.264/AAC MP4、24 fps**，字幕可单独导出为 **SRT/VTT**。独立字幕文件不等于自动烧录在画面里。安装包包含 x265 编码能力，但当前界面没有因此新增 H.265 导出选项。

## 修改已有视频

- **自然语言修改**：在创作台针对某一镜提出修改，审阅更新内容与关键帧，再继续制作；未变化且仍有效的产物会复用。
- **元素编辑**：选中已生成的代码分镜，打开“元素编辑”，调整受支持的文字、图片和 SVG，以及位置、大小、颜色、图层、显示时间和二维动画。保存后重新检查受影响画面。
- **时间线剪辑**：打开“时间线剪辑”，裁剪、分割、重排视频/图片片段，添加多条配乐或音效、文字/图片图层，调整音量和淡入淡出。可设置旁白出现时压低配乐。
- **检查剪辑结果**：保存剪辑后点击“预览剪辑”生成实际合成预览，再“生成成片”。源片段播放器不会实时呈现全部覆盖图层和混音效果。

元素编辑支持受控的二维节点；任意第三方组件、Canvas/WebGL 内部对象不能全部直接编辑。全片时间线目前是顺序视频主轨、定时图层和多轨音频，不包含专业剪辑软件的全部功能，如跨镜头溶解、调色、波形编辑或自由重叠视频轨。导入视频不会自动生成语音转录字幕。

## 下载、离线与恢复

默认渲染使用随包 Electron，不需要单独下载 Chrome。仅为兼容需求，才在 **设置 → 引擎与连接 → 视频渲染** 切换到 Chrome，并按运行组件提示准备。切换后重新生成并审阅预览。

Windows 安装包内已有 FFmpeg/ffprobe。默认 Virgil、Long Cang 和界面字体可离线使用；其他五款白板字体首次使用时下载并校验。下载失败时保留项目并提供错误，恢复网络后重试；离线缺失的字体需要先下载，不能因为内置了默认字体就假定所有风格资源均已缓存。

运行组件入口支持离线模式和离线缓存导入。它只控制组件获取，不会使在线模型或云端配音变成离线服务。样片、字体和组件各自管理缓存；没有对应缓存时，离线模式不能代替下载。GitHub 或上游不可访问时，使用已有缓存或运行组件的离线导入入口。

取消或中断后重开本地项目，按当前检查点恢复任务。保留仍有效的完成产物；遇到错误先查看所在阶段和诊断，不必删除项目后从头开始。给项目、音频和视频缓存保留足够磁盘空间。

## 常见问题

| 情况 | 建议操作 |
| --- | --- |
| 安装后没有可用创作引擎 | 安装一个本机 CLI、完成登录和模型配置，再重启应用并检测连接 |
| 检测成功但任务失败 | 查看提供方错误，检查账号权限、模型名称、网络和额度；不要把检测成功当成推理成功 |
| 制作按钮提示先确认 | 回到当前草案、分镜或关键帧入口，修复问题并确认当前版本 |
| 样片或字体下载失败 | 恢复网络后重试；已完成校验的缓存可以离线复用 |
| 配音失败或无声 | 核对所选方式、音色、服务地址/区域、凭据；先用 Windows 系统语音验证本地链路 |
| GPU 没有启用 | 可能是设备不可用、不支持当前任务，或实测比 CPU 慢；自动使用 CPU 是预期行为 |
| 首次导出较慢 | 首次编译、配音、资源准备和 GPU 能力探测有开销；后续可复用有效缓存 |
| 剪辑预览缺少图层或混音 | 保存剪辑并生成“预览剪辑”，不要只看源片段预览 |
| 误下了 Source code ZIP | 回到 Release 的 Assets，下载以 Setup.exe 结尾的安装包 |

## 备份、许可与反馈

项目和产物保存在本机。备份应包含项目目录及相关素材；仅导出的方案或字幕不能替代完整项目备份。不要随意删除项目内部缓存和场景文件来解决未知错误。

在 **设置 → 关于与诊断 → 第三方许可与源码** 查看随包许可。FFmpeg/ffprobe 完整对应源码和构建记录见 [source v2 Release](https://github.com/makesynt/seqvio-studio/releases/tag/ffmpeg-seqvio-source-v2)。

在 [Issues](https://github.com/makesynt/seqvio-studio/issues) 反馈时提供应用版本、Windows 版本、引擎/模型、失败阶段、具体报错及最小复现步骤。提交截图、日志或项目片段前，移除 API Key、令牌和私人资料。
